## What this project does
- **Part A (GOTO):** number classifier, salary review using GOTO, an illegal GOTO with its fix, and the salary review rewritten without GOTO.
- **Part B (Functions):** annual salary, years of service, tax calculator, department name, and using the functions inside SQL queries.
- **Part C (Combined):** a payroll validator function and a reflection.

## Repository structure
- `00_setup/` - table creation and sample data
- `01_goto/` - A1 to A4
- `02_functions/` - B1 to B4 and C1
- `03_tests/` - B5 and test scripts
- `screenshots/` - output screenshots
- `docs/REFLECTION.md` - reflection

## How to run
1. Run `00_setup/create_tables.sql`.
2. Run the functions in `02_functions/`.
3. Run the programs in `01_goto/`.
4. Run the test files in `03_tests/`.
5. Verify results against the screenshots.

(Run each file with **Run Script** in Oracle FreeSQL so the `/` terminators work.)
